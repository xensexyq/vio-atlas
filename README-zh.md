## 2. 从哪里开始

- 首套算法基线：OpenVINS；双目或广角对照：Basalt；完整视觉惯性 SLAM：OKVIS2。
- 先验证软同步：保留设备源时间戳，使用 Kalibr 检查时间偏移，并比较 OpenVINS 或 VINS 系列的在线估计。
- MCU 与 PC 时钟映射：优先参考 CuckooTimeTranslator 和 MAVLink TIMESYNC，两者分别代表单向映射和双向对时。
- 硬件产品化：优先参考 VersaVIS 的触发、曝光反馈、统一计时及图像关联；STM32 实现可结合 LIV_handhold 与 LC-Robotics 工程。
- 形成可交付能力：同步协议、标定文件、跟踪状态、录包回放和误差评估一起交付。

软件同步和硬件同步应配合设计：设备记录可靠的测量事件时间，PC 完成时钟转换、时间偏移估计、缓存和关联。固定偏移可估计，随机抖动、时钟漂移与丢包要分别处理。PC 收包时间可以记录，但不能直接作为传感器同步依据。

## 3. 参考流程

```mermaid
flowchart LR
  S[相机与 IMU 源数据] --> T[事件时间标记与时钟映射]
  T --> C[空间与时间标定]
  C --> V[VIO 或视觉惯性 SLAM]
  V --> E[轨迹评估与记录回放]
```

没有硬触发也可以开始 VIO 原型验证；是否稳定取决于实际时间戳、运动、曝光与图像质量。视触觉可以先对齐记录，是否融合由后续模型决定。

## 4. 阅读与选型

无需安装本合集。先阅读[完整项目目录](docs/CATALOG-zh.md)，按相机、IMU 和计算平台选择候选，再使用上游仓库的安装说明。各项目的 ROS 版本、依赖和硬件要求不同，合集不提供统一安装命令。

从爪采用鱼眼和 IMU、PC 负责 VIO 时，参考[集成指南](docs/INTEGRATION-zh.md)核对曝光语义、源时间戳、帧号、接口、标定与工况评估。

## 5. 维护与许可

更新条目时同时检查官方源码入口、能力、依赖、许可和对应翻译。项目有源码或论文结果，不代表已在目标硬件上完成验证。

所有项目归各自作者所有，本仓库只整理链接与说明。开源许可、依赖、模型权重及硬件设计应分别核对；非商业或平台受限方案在目录中明确说明。本仓库尚未指定自身内容的复用许可证，上游许可不自动适用于本合集。
